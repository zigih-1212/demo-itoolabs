# ADR 002. Vue 3 на фронтенде

## Контекст

Нужно выбрать фронтенд-фреймворк. Задача — сделать качественное приложение
с перспективой масштабирования, но без избыточной сложности.

## Варианты

1. **React** — самый популярный, огромная экосистема.
2. **Vue 3** — низкий порог входа, официальные решения «из коробки»
   (маршрутизация, состояние), отличная документация на русском.
3. **Svelte** — элегантный, но меньшая распространённость на рынке.

## Решение

Использовать **Vue 3 + TypeScript + Vite** с официальными библиотеками
Pinia (состояние) и Vue Router (маршрутизация).

## Последствия

**Плюсы:**
- Единая, согласованная экосистема: router, store и сборка не требуют долгого
  выбора сторонних библиотек.
- `<script setup>` и реактивность читаются почти как обычный код — важно для
  демонстрационного проекта.
- Composition API позволяет переиспользовать логику (composables), например
  диалог подтверждения.

**Обоснование применительно к вакансии:**
- Часть вакансий предполагает миграцию на Vue и готовность работать с ним —
  этот стек демонстрирует такую готовность напрямую.

**Минусы:**
- Меньше готовых компонентов «на всё», чем в React-экосистеме. Для этого
  проекта собственная библиотека компонентов (`components/ui`) закрывает
  потребности и заодно демонстрирует навык их проектирования.
