# Записи об архитектурных решениях (ADR)

ADR (Architecture Decision Record) — короткий документ, который фиксирует
**одно важное решение**: контекст, варианты, выбор и последствия. Когда через
полгода возникнет вопрос «почему сделано именно так?», ответ уже будет здесь,
а не только в чьей-то памяти.

Формат каждой записи: **Контекст → Варианты → Решение → Последствия**.
